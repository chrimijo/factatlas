# Changelog

## 1.1.0 — 2026-10-27

- Automatic French/English detection, priority `--lang fr|en`, invalid/conflicting parameter clarification and legacy aliases.
- Complete report localization, multilingual research, original-document verification, preserved authentic names and quotations.
- English workflow/documentation, seven translated modules and three specializations, bilingual templates/registers/examples/tests.
- Localized score calculation/errors, English and legacy JSON schemas, stronger package validation.
- Identification moved ahead of configuration in templates; evidence rules and model recommendations preserved.
- Self-contained dependency-free bundle updated from v1.0.0 archive.

## 1.0.0 — 2026-10-27

First standalone public package, with numbering separate from earlier V4.x–V5.x meta-prompts. Seven subject modules, three product specializations, automatic/composite classification, five modes, Wikipedia as an index leading to original evidence, sourced numerical discrepancy decisions, separate confidence/coverage weighted scores, environment-aware model recommendations without fictitious switches, templates, scenarios, README and optional arithmetic script.
