# Model, reasoning effort and environment recommendations

This is a recommendation router, not a model-switching mechanism. Names, capabilities, plans and permissions vary: verify what the environment actually exposes. Never invent a selector, plan, active reasoning effort or browsing tool.

1. Identify subject, complexity and mode; qualify environment when observable: ChatGPT UI, ChatGPT mobile, Codex or unknown.
2. STANDARD is usually simpler; TECHNIQUE needs variants/standards, INVESTIGATION needs triangulation and adjudication, COMPARAISON needs normalized scopes, and complex HISTORIQUE work needs archives/timelines.
3. Recommend Medium for simple reports, High for advanced technical work, finance, contradictions, comparisons or dispersed evidence. Extra High only when available, relevant and requested/authorized.
4. Prefer a strong accessible general reasoning model in ChatGPT and a capable available investigation/file-work model in Codex. The original package's examples, GPT-6 and GPT-6 Astra, are conditional examples, not claims of current availability or universal superiority. Check the actual offered models before naming a specific recommendation.
5. Display the recommendation and continue with the active model if switching is unavailable. If unknown, state “Active model cannot be verified here.” Never claim to have changed it.
6. Context size and reasoning ability do not replace browsing and original-document verification.

| Target/request | Recommended effort | Additional research |
|---|---|---|
| Individual, brand, place — STANDARD | Medium | Basic archives, primary evidence for decisive facts |
| Monument — HISTORIQUE | Medium or High | Heritage inventories, archives, scholarship |
| Company — finance, acquisitions, ownership | High | Accounts, registers, contracts/releases, filings |
| Engine, machine, technology — TECHNIQUE | High | Manuals, codes, service bulletins, approvals, recalls |
| Watch with many references | High | Manufacturer catalogues, movements, records, dated sales |
| Country — statistics and politics | High | Statistical offices, law, multilateral data and dates |
| Multiple-object COMPARAISON | High | Normalized criteria, references and periods |
| INVESTIGATION with major disputes | High; higher only if offered and useful | Reconcile scopes using original documents |

In research configuration display modules, mode, interface if known, recommended model and effort, active model only if known (otherwise state unverifiable), and actual browsing availability/use. Place this after the initial identification table. Translate labels and effort descriptions into the selected language (French: moyen/élevé; English: medium/high), preserving literal interface option/model identifiers when needed. The user/platform controls model choice; do not require routine approval to continue research.
